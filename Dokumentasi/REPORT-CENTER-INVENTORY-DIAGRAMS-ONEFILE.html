Sequence — filter user sampai payload

Alur request dari UI ke SQL dan kembali ke ringkasan/baris.

Sequence 
sequenceDiagram
  actor U as User
  participant V as ReportViewerClient
  participant A as API /api/reports/inventory
  participant D as Domain builder
  participant G as SQL Gateway
  participant S as SQL Server

  U->>V: Set period + filters
  V->>A: GET/POST reportId + params
  A->>D: build query / aggregate plan
  D->>G: SELECT only (RTRIM, period map)
  G->>S: execute read-only
  S-->>G: recordset
  G-->>D: rows
  D-->>A: summary + rows + flags
  A-->>V: JSON payload
  V-->>U: KPI + table + stream status
Flags penting: streamComplete · placeholder_zero · scope export/AI.

# Coding Conventions

- [rule:typescript] TypeScript uses strict mode, 2-space indentation, single quotes in TS/TSX.
- [rule:naming] Report IDs and routes use kebab-case; React components use PascalCase; functions, variables, and hooks use camelCase.
- [rule:comments] Prefer existing helpers over duplicate logic; comments explain sharp edges or non-obvious constraints.
- [rule:simplicity] Prefer native APIs and existing dependencies; add minimum code that works.

# Glossary

**Last verified:** 2026-07-21

| Term | Meaning |
|---|---|
| **Estate / Kebun** | Plantation source profile; MSSQL `db_ptrj` |
| **Pabrik / Mill** | Mill source profile; MSSQL `db_ptrj_mill` |
| **Report Center** | In-app analytics UI under `/report-center` |
| **Procurement module** | Inventory + purchasing + workshop stock analytics entry |
| **RPTIN1000015** | Monthly Stock Account Movement Details report code |
| **Accounting period** | AccYear/AccMonth used by month-end tables |
| **Actual period** | Calendar year-month operators select in UI |
| **Movement window (MC)** | Lookback window for movement category counts |
| **Stock analysis codes** | e.g. DEADS, MEMOV, SLMOV groups |
| **IFESS** | Field/superapp client ecosystem + control server |
| **Query gateway** | Service executing SQL (MSSQL gateway and/or Firebird isql) |
| **isql** | Firebird Interactive SQL CLI |
| **Payload-side filter** | Filter applied in Node after SQL returns rows |
| **placeholder_zero** | Measure defined but not calculated (returns 0) |
| **Live report** | Catalog status allowing open/export against real handler |
| **SQL gateway** | HTTP service used by dashboard for inventory SQL execution |
